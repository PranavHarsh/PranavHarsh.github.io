face-detect-url

Face finder · Link-safety check · Live
  • Finds the face in any picture. Give it an image link or a web page address, or paste, drop or upload a picture, and it draws a box around the face.
  • Every link gets a verdict: Safe, Suspicious or Dangerous, shown as three lights, with the reasons listed in plain words.
  • Dangerous links are blocked before the picture is opened, including look-alike addresses and fake sign-in pages.
  • Private by design. Face detection runs in your browser, so a picture you upload never leaves your device.
  • Sign in and it remembers you, with a running count of your checks.
  • Built and deployed solo — a React front end with a Node.js API behind it.
